# MMF WAM/WAL 规划器

面向货币市场基金（MMF）组合管理的配置测算工具。录入当前持仓、机构集中度上限和可投资产品报价，即可比较新增资金的配置方案，查看收益与期限之间的取舍。

- **配置优化**：在资金、WAM、WAL、机构集中度及产品额度约束内，寻找交易后加权 YTM 最高的配置。
- **收益前沿**：查看不同 WAM 或 WAL 上限下的最高可达 YTM。
- **目标收益反推**：输入目标 YTM，寻找满足目标的最短 WAM 或 WAL 上限，并生成对应配置。
- **现金压力测算**：按手动设置的赎回压力收紧机构可配置额度。
- **多语言界面**：支持简体中文、繁体中文和英文，以及浅色、深色模式。

目前支持**净申购测算**，净赎回功能暂未开放。测算结果用于辅助分析；“约束通过”仅代表工具已建模的检查项通过，不构成投资建议或完整合规结论。

## 快速开始

需要 Node.js **22.13.0 或更高版本**及 npm。在项目目录执行：

```bash
npm ci
npm run dev
```

打开终端输出的本地地址即可使用。页面自带示例数据，无需配置数据库或 API 密钥。

首次体验可以直接查看默认配置结果，调整新增资金或期限上限后重新计算。顶部的“12家银行模拟示例”提供包含 30 个产品、31 笔持仓的较大组合；“恢复示例”可回到基础示例。**切换示例会替换当前输入**，示例中的产品、利率和金额均为模拟数据。

## 使用指南

### 1. 录入当前持仓与机构

进入“当前持仓”工作区，新增或选择合作机构，设置各机构集中度上限，再逐笔录入持仓：

- 当前估值金额及 YTM；无息资产的 YTM 请明确填 `0`。
- 剩余 WAL 天数；固定利率产品的 WAM 可留空，默认采用 WAL，浮息产品填写适用的剩余重定价天数。
- 集中度归属机构。确实不计入单一机构统计的资产需要明确选择排除，尚未选择归属的持仓会阻止计算。
- 纯现金标记为“现金 · 计入缓冲”，其 WAM、WAL 自动按 `0` 计算。

当前 AUM、加权 YTM、WAM、WAL、现金缓冲及机构敞口均由持仓自动汇总，无需重复填写。正金额持仓缺少收益或期限信息时，需补全后才能测算。

### 2. 更新今日可投产品

进入“今日可投”工作区，为每项报价填写机构、产品名称、利率、WAM/WAL 天数和可用额度。WAM 留空时采用 WAL，WAM 不得大于 WAL。

### 3. 设置资金和约束

回到“配置测算”工作区，填写新增资金、WAM/WAL 上限，以及手动赎回压力比例或金额。压力比例以**当前 AUM**为基数；按金额输入时，金额保持固定。

工具将压力后 AUM 用于收紧机构额度。压力金额超过当前现金缓冲时会停止计算，因此请先确认现金持仓录入完整。

### 4. 查看配置与收益前沿

执行计算后，可查看推荐产品、配置金额、交易后组合指标、未配置资金及约束复核结果。

切换 WAM/WAL 收益前沿可以比较不同期限上限；选择曲线上的期限点可更新配置。也可输入目标交易后 YTM，反推所选期限指标的最短可行上限，另一项期限上限仍然生效。

修改持仓、报价或参数后，请重新计算。切换工作区不会清除输入。

## 输入与计算口径

| 项目 | 约定 |
| --- | --- |
| 金额 | 使用同一估值日和记账币种。金额单位选择仅改变标签，**不会换算已有数值**。 |
| 数字格式 | 支持 `1,000.50` 这样的千位分隔格式，不将逗号识别为小数点。 |
| 收益率 | 按百分数填写，例如 `2.5` 表示 `2.5%`。加权 YTM 是年化收益近似指标，并非持有期现金流收益预测。 |
| 期限 | 按天填写，剩余天数需手动更新，不会随日期自动递减。 |
| 配置金额 | 使用连续金额优化，不处理最小起投额或交易金额步长。 |
| 未配置资金 | 视为零收益、零 WAM、零 WAL 的现金，不计入当前持仓已确认的现金缓冲。 |
| 结果精度 | 汇总数值最多显示三位小数，计算使用未舍入值；目标收益反推的期限上限向上保留至 `0.01` 天。 |

交易后 YTM、WAM、WAL 均以“当前 AUM + 新增资金”为分母，按金额加权。模型允许部分新增资金留作现金。

现金压力约束采用以下口径：

```text
压力金额 = 当前 AUM × 压力比例（或直接输入的金额）
压力后 AUM = 当前 AUM + 新增资金 − 压力金额
机构最多新增金额 = 压力后 AUM × 机构上限 − 当前机构敞口
```

压力情景保守地维持现有机构敞口不变，包括归属于机构的现金，不模拟具体支付账户或资产赎回顺序。压力后 AUM 只用于机构额度约束，不作为交易后收益及期限指标的分母。

收益前沿以整数天采样，并补充最紧可行期限和估算的最高收益起点，适合比较配置取舍，不是任意精度的连续曲线。

## 适用范围与限制

工具内置 WAM 60 天、WAL 120 天的上限，允许设置更严格的目标；单一机构集中度最高可录入 25%。界面以 10% 为一般提示线，超过该值的适用条件需由使用者确认，不能将“可录入”理解为“合规”。

模型检查资金总额、期限、机构额度、单项报价额度及基础数据关系，但不会自动判断产品资格、单项工具 397 天限制、发行实体与集团合并口径、DLA/WLA 或其他完整 SFC 条件。正式使用配置前，应结合实际产品条款和适用规则进行投资、风控及合规复核。

## 数据保存

合作机构备选库、语言和主题偏好保存在当前浏览器中。**持仓、报价、当前机构表、资金与目标参数、金额单位不会持久保存，刷新或关闭页面后会丢失，重新打开时恢复示例数据。**

“恢复示例”不会清除已保存的合作机构备选库；更换浏览器或清除浏览器数据后，备选库与偏好不会自动同步。

## 本地开发

项目使用 React、TypeScript 和 Vinext/Vite，构建输出面向 Cloudflare Workers。

```bash
npm test            # 运行计算逻辑与输入校验测试
npm run typecheck   # TypeScript 类型检查
npm run lint        # 代码检查
npm run build       # 生成生产构建
npm start           # 在本地预览生产构建，需先完成 build
```

主要文件：

| 路径 | 内容 |
| --- | --- |
| `app/page.tsx` | 工作区、表单、配置结果及图表 |
| `lib/planner.ts` | 数据校验、优化求解、收益前沿与目标反推 |
| `lib/holding-metrics.ts` | 持仓加权指标汇总 |
| `lib/numeric-input.ts` | 数字输入解析 |
| `lib/large-example.ts` | 大组合模拟数据 |
| `lib/i18n.ts` | 多语言文案与偏好设置 |
| `tests/` | 自动化测试 |

修改计算规则后，建议补充相应的回归测试，并运行测试、类型检查和生产构建。
