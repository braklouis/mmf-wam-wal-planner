# 利率期限结构原型（未开放）

范围：手工输入同币种、同估值日、同年化口径的“期限天数／年化报价利率”节点，估算区间内未报价期限的利率。当前不提供输入界面，导航仅有禁用入口；不接入报价、优化、持仓或存档。

初步方法：分段线性插值。对相邻节点 (t1,r1)、(t2,r2)，r(t) = (1-w)r1 + w r2，w=(t-t1)/(t2-t1)。利率2.5表示2.5%，期限统一为天。例：30天2.4%、90天3.2%，估计60天为2.8%。命中节点直接返回原始报价，插值返回相邻期限作为依据。

允许负利率、平坦和倒挂结构。不合并重复期限，不外推；只有一个节点时仅支持该节点本身。输入可乱序，原始数组不变。

这不是零息曲线、贴现曲线、远期利率或债券定价模型；插值利率不是实际可成交报价。暂不从票息或YTM推导现金流，也不对不同机构的信用利差作混合处理。

开放前需确定：这条曲线代表哪个币种与报价来源，是否按机构分别输入，以及结果只作参考还是允许用户确认后生成报价。目前先保留独立纯函数与回归测试，不改变现有配置模型。
