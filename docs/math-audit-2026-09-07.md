# 计算逻辑与数学复核（2026-09-07）

## 结论与范围

复核当前工作区中的持仓汇总、逐项／汇总期限／简易模式、申购优化、同比例赎回、现金压力、机构／实体／集团集中度、报价矩阵与导入、收益前沿、目标收益反推及存档字段。核心线性规划和金额加权公式，在下列明确假设下自洽；发现并修复了约束遗漏及界面口径问题。不能把有限测试理解为任意输入均正确的数学证明，也不能把本工具的可行结果当作完整监管合规结论。

## 已修复的问题

1. **赎回漏检共享集中度（高优先级）**：原先只检查每一行机构，未检查同一实体合并上限及集团上限。例：AUM 100，两家同集团银行各持有 12，集团上限 20%；同比例赎回 20 后集团仍占 24%，原来会成功返回。现在在交易前和交易后检查共享上限，并检查集团归属、上限一致性及例外确认。
2. **手工期限允许矛盾输入（高优先级）**：汇总期限或简易模式可以输入 WAM 40、WAL 20 并参与优化。现在申购、赎回、收益前沿和反推均拒绝这种输入，界面也提示原因。
3. **赎回入口缺少敞口对账（中优先级）**：直接调用赎回计算时，传入机构敞口可能与持仓明细不同，导致变动金额错误。现在检查持仓名称、标识、金额、归属及总额，并逐机构核对敞口。
4. **赎回界面口径混用（中优先级）**：赎回模式原先显示仅作用于申购的现金压力面板，集团剩余额度还使用申购压力分母。现在赎回模式不显示该面板，集团剩余额度按赎回后 AUM 与同比例缩减后的集团敞口计算。

## 公式核对

所有金额使用同一币种、估值口径及单位，收益率使用百分数数值（2 表示 2%）。

设当前资产 A、申购 S、当前加权收益 y、当前期限 W/L，产品配置金额 x_i、收益 r_i、期限 w_i/l_i。

- 交易后资产：P = A + S。
- 收益：(A × y + Σ x_i × r_i) / P。
- WAM：(A × W + Σ x_i × w_i) / P；WAL 同理。
- 资金限制：x_i ≥ 0，Σ x_i ≤ S；产品上限 x_i ≤ cap_i。
- 未配置金额：S − Σ x_i，按零收益、零期限处理。
- 最大化 Σ x_i × r_i 与最大化交易后加权收益等价，因为 A、y、P 在一次求解中固定。
- 期限约束转换为 Σ x_i × w_i ≤ P × W上限 − A × W；WAL 同理。若右端为实质负数，新增资金全部留现金也不可行。
- 代码将金额除以 P 再求解，以减轻金额尺度带来的数值问题；输出恢复金额并复核硬约束。

现金压力：赎回压力 R 为 A × 压力比例或直接输入金额；仅允许 R 不超过现有现金。机构与共享额度使用 P − R 为分母，并保守保持机构敞口不变。收益和期限输出仍表示压力发生前的配置，不是压力后的指标。

同比例赎回：赎回 D，比例 q = D/A；各持仓剩余 h_i × (1−q)，AUM = A−D。在所有资产按相同比例退出且忽略费用／价差的假设下，YTM、WAM、WAL和各集中度比例不变。接近全部赎回时另有数值稳定性及对账检查。

## 独立验证

- 新增 300 组固定随机种子案例，每组三产品，覆盖持仓、汇总期限及简易模式，正／负收益、固定／浮动期限、有限／无限报价上限、机构与集团约束、现金压力。
- 独立校验器在原始金额单位中构建约束，并枚举三条约束边界的交点计算最优值；不调用生产 simplex 或其约束构建函数。300 组最优收益与生产求解器全部匹配，同时核对加权收益及资金守恒。
- 闭式算例：A=100、y=2%、WAM=20、WAL=40，申购100；报价6%、WAM80、WAL100。达到2.5%只需投资50，最低WAM上限30、WAL上限45。反推与收益前沿均符合此公式。
- 新回归测试在修复前复现了共享集中度漏检和矛盾期限输入，修复后通过。
- 全部73项测试通过，包括原有极小／极大金额、接近全部赎回、收益前沿、存档及加密测试。加密测试不构成金融计算的证据；本次独立数学案例集中在 tests/math-audit.test.ts。

## 仍需正确理解的模型边界

- **加权YTM是近似指标**，不是用全组合未来现金流反解得到的精确IRR；不含管理费、交易成本、实际计息日历和不同日计息规则的调整。
- **简易模式明确跳过集中度与现金压力**；汇总期限模式保留这些约束，但信任用户输入的组合期限，不能反向证明其与底层持仓一致。
- **同比例赎回是情景计算**，不代表定存或债券能实际按比例立即变现，不会选择最优赎回资产，也不计算提前退出损失。
- **现金压力只收紧集中度**，不模拟压力后收益和期限，也不判断每日／每周流动资产要求。
- **金额单位选择仅更改标签**，不会把现有100亿元自动换算为10,000百万元；所有输入必须始终使用一致单位。月期限导入按1M=30天等固定约定，不按实际起息日计算。
- **集中度以AUM等于NAV为前提**，且依赖机构归属、集团、排除标记及上限输入正确。用户设置例外上限不等于程序核验了例外资格。
- **完整监管覆盖不在当前模型内**：例如产品剩余最终到期限制、资产资格、信用质量、每日／每周流动性、衍生品及担保例外等，不应从“满足已录入约束”推断全部合规。
